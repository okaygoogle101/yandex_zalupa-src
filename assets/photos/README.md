# Фото для панелей

Сюда кладутся 21 изображение с именами `f1.jpg` … `f21.png` (расширение любое, которое читает Pillow). Затем:

```powershell
cd assets\wheat_field
py build_photos.py ..\photos
```

Скрипт добавит в WAD текстуры `YZ_PHOTO_01..21` и табличку `YZ_CREDITS`.

Имена `f18` соответствует текстуре `YZ_PHOTO_18` — она вешается на голову пугала. Остальные распределяются по комнатам 2–6 согласно `docs/MAP.md`.

Сами фотографии в репозиторий не входят.
