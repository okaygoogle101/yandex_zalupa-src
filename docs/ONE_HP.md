# Как поставить тюкам и игле 1 HP

В версии 0.8 по умолчанию стоят `seno_bale_hp 1000` и `seno_needle_hp 100`. Для теста удобнее 1 HP: тогда любой удар ножом разрушает тюк.

## Способ 1 — без пересборки, через конфиг

Открой `cstrike/addons/amxmodx/configs/amxx.cfg` и добавь строки:

```
seno_bale_hp 1
seno_needle_hp 1
```

Затем смени карту или перезапусти сервер. Плагин читает значения в момент создания стога, поэтому менять их на лету посреди этапа смысла нет: текущий стог останется с прежним здоровьем.

Если не хочешь трогать файл, то же самое можно выполнить в консоли сервера:

```
amx_cvar seno_bale_hp 1
amx_cvar seno_needle_hp 1
```

После этого нужен новый раунд или перезаход на карту.

Проверка: в логе AMXX при старте этапа будет `bales=204`, а первый же удар ножом по тюку должен его разрушить со звуком и обломками. Если тюк держит удар — значит, в конфиге осталось старое значение или стог создан до изменения cvar'а.

## Способ 2 — навсегда, в исходнике

В `plugins/yz_seno_pyramid.sma` найди строки регистрации cvar'ов:

```pawn
g_cvar_hp = register_cvar("seno_bale_hp", "1000");
g_cvar_needle_hp = register_cvar("seno_needle_hp", "100");
```

Замени значения на `"1"` и пересобери плагин:

```powershell
amxxpc.exe plugins\yz_seno_pyramid.sma -i<путь>\include -o yz_seno_pyramid.amxx -C+
```

Положи новый `.amxx` в `cstrike/addons/amxmodx/plugins/` с заменой. Карту пересобирать не нужно: здоровье задаётся только плагином.

## Что именно происходит внутри

- `register_cvar` задаёт значение по умолчанию.
- При создании стога плагин берёт `max(1, get_pcvar_num(...))` и записывает в `pev_health` каждого тюка и иглы.
- Удар ножом уменьшает `pev_health` на величину урона; при `<= 0` тюк разрушается.
- Значение из `amxx.cfg` всегда перекрывает значение по умолчанию из кода.

## Если хочется промежуточный вариант

Можно поставить любое положительное число, например `seno_bale_hp 35` — тюк выдержит несколько ударов, а эффект разрушения сыграет только на последнем. При `1` эффект совпадает с каждым ударом.
